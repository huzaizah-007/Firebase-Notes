# Firebase Notes

## 📱 About

Firebase Notes is a modern Android notes application built using Kotlin and Jetpack Compose. It allows users to securely create, edit, search and delete notes with Firebase backend integration.

## ✨ Features

- User Registration
- User Login
- Firebase Authentication
- Create Notes
- Edit Notes
- Delete Notes
- Search Notes
- Cloud Firestore
- User-specific Notes
- Dark Mode UI
- Responsive UI
- Smooth Animations

## 🛠️ Technologies

- Kotlin
- Jetpack Compose
- Android Studio
- MVVM Architecture
- Firebase Authentication
- Cloud Firestore
- Kotlin Coroutines
- Material 3
- Git & GitHub

## 🏗️ Architecture

The application follows the MVVM (Model-View-ViewModel) architecture pattern.

## 🚀 Getting Started

1. Clone the repository.
2. Open the project in Android Studio.
3. Connect the project with your Firebase project.
4. Add the required Firebase configuration.
5. Allow Gradle to sync.
6. Run the application on an Android device or emulator.
